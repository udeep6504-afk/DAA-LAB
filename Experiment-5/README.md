# Experiment 5

## Aim

To find the minimum and maximum values in an array by applying the Divide and Conquer technique.

## Algorithms

- Divide and Conquer Min-Max Algorithm
- Naive Min-Max Search (for performance comparison)

## Result

The minimum and maximum values in an array were successfully identified using the Divide and Conquer strategy, which optimized the number of comparisons compared to the naive approach, aligning with the theoretical formula of $3n/2 - 2$.
